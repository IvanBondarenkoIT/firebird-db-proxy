# Firebird Database Proxy API - Руководство для разработчиков

**Версия:** 1.0  
**Дата:** 6 ноября 2025  
**URL API:** `http://85.114.224.45:8000`

---

## 🎯 ЧТО ЭТО ТАКОЕ

Это REST API для безопасного доступа к базе данных Firebird. Позволяет выполнять SQL запросы (только SELECT) и получать данные из БД через HTTP запросы.

**Возможности:**
- ✅ Выполнение SELECT запросов к базе данных
- ✅ Получение списка таблиц
- ✅ Получение схемы таблиц
- ✅ Безопасность (только чтение, защита токенами)
- ✅ Кеширование (быстрые ответы на повторяющиеся запросы)

---

## 🔑 АУТЕНТИФИКАЦИЯ

Все запросы (кроме health check) требуют Bearer Token аутентификации.

**Формат:**
```
Authorization: Bearer ВАШ_ТОКЕН_64_СИМВОЛА
```

**Где получить токен:**
- Обратитесь к системному администратору
- Токен выдается индивидуально каждому приложению/разработчику

```json
  "uptime_seconds": 12345.67,

  "timestamp": "2025-11-06T12:00:00"
}
```

---

### 2. Выполнение SQL запроса

**POST** `/api/query`

Выполнение SELECT или WITH запроса к базе данных.

**Требования:**
- ✅ Только SELECT и WITH запросы
- ❌ UPDATE, DELETE, INSERT, DROP, ALTER запрещены
- ✅ Параметризованные запросы поддерживаются

**Заголовки:**
```
Authorization: Bearer ВАШ_ТОКЕН
Content-Type: application/json
```

**Тело запроса:**
```json
{
  "query": "SELECT * FROM TABLE_NAME WHERE ID = ?",
  "params": [123]
}
```

**Параметры:**
- `query` (обязательный) - SQL запрос (строка)
- `params` (опциональный) - параметры запроса (массив)

**Пример запроса:**
```bash
curl -X POST http://85.114.224.45:8000/api/query \
  -H "Authorization: Bearer ВАШ_ТОКЕН" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "SELECT FIRST 10 * FROM STORGRP ORDER BY NAME"
  }'
```

**Успешный ответ (200):**
```json
{
  "success": true,
  "data": [
    {"ID": 1, "NAME": "Группа 1"},
    {"ID": 2, "NAME": "Группа 2"}
  ],
  "rows_count": 2,
  "execution_time": 0.005,
  "error": null,
  "timestamp": "2025-11-06T12:00:00"
}
```

**Ошибка (400) - невалидный SQL:**
```json
{
  "success": false,
  "data": null,
  "rows_count": null,
  "execution_time": null,
  "error": "SQL validation failed: Forbidden operation detected: UPDATE",
  "timestamp": "2025-11-06T12:00:00"
}
```

**Ошибка (401) - неверный токен:**
```json
{
  "detail": "Invalid authentication credentials"
}
```

## 💻 ПРИМЕРЫ КОДА

### Python

```python
import requests

# Настройки
API_URL = "http://85.114.224.45:8000"
TOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"

headers = {
    "Authorization": f"Bearer {TOKEN}",
    "Content-Type": "application/json"
}

# Пример 1: Простой SELECT запрос
def get_data(query):
    response = requests.post(
        f"{API_URL}/api/query",
        json={"query": query},
        headers=headers
    )
    
    if response.status_code == 200:
        data = response.json()
        if data["success"]:
            return data["data"]
        else:
            print(f"Ошибка: {data['error']}")
            return None
    else:
        print(f"HTTP ошибка: {response.status_code}")
        return None

# Использование
result = get_data("SELECT FIRST 10 * FROM STORGRP ORDER BY NAME")
if result:
    for row in result:
        print(row)

# Пример 2: Параметризованный запрос
def get_by_id(table, id_value):
    query = f"SELECT * FROM {table} WHERE ID = ?"
    response = requests.post(
        f"{API_URL}/api/query",
        json={"query": query, "params": [id_value]},
        headers=headers
    )
    
    if response.status_code == 200:
        data = response.json()
        if data["success"] and data["data"]:
            return data["data"][0]  # Первая строка
    return None

# Использование
item = get_by_id("STORGRP", 123)
if item:
    print(f"Найдено: {item}")

# Пример 3: Получение списка таблиц
def get_tables():
    response = requests.get(
        f"{API_URL}/api/tables",
        headers=headers
    )
    
    if response.status_code == 200:
        data = response.json()
        return data["tables"]
    return []

# Использование
tables = get_tables()
print(f"Доступно таблиц: {len(tables)}")
```

### JavaScript/TypeScript (Node.js)

```javascript
const axios = require('axios');

// Настройки
const API_URL = 'http://85.114.224.45:8000';
const TOKEN = 'ВАШ_ТОКЕН_ЗДЕСЬ';

const headers = {
  'Authorization': `Bearer ${TOKEN}`,
  'Content-Type': 'application/json'
};

// Пример 1: Простой SELECT запрос
async function getData(query) {
  try {
    const response = await axios.post(
      `${API_URL}/api/query`,
      { query },
      { headers }
    );
    
    if (response.data.success) {
      return response.data.data;
    } else {
      console.error('Ошибка:', response.data.error);
      return null;
    }
  } catch (error) {
    console.error('HTTP ошибка:', error.response?.status, error.message);
    return null;
  }
}

// Использование
(async () => {
  const result = await getData('SELECT FIRST 10 * FROM STORGRP ORDER BY NAME');
  if (result) {
    result.forEach(row => console.log(row));
  }
})();

// Пример 2: Параметризованный запрос
async function getById(table, id) {
  try {
    const response = await axios.post(
      `${API_URL}/api/query`,
      {
        query: `SELECT * FROM ${table} WHERE ID = ?`,
        params: [id]
      },
      { headers }
    );
    
    if (response.data.success && response.data.data.length > 0) {
      return response.data.data[0];
    }
    return null;
  } catch (error) {
    console.error('Ошибка:', error.message);
    return null;
  }
}

// Пример 3: Получение списка таблиц
async function getTables() {
  try {
    const response = await axios.get(
      `${API_URL}/api/tables`,
      { headers }
    );
    return response.data.tables || [];
  } catch (error) {
    console.error('Ошибка:', error.message);
    return [];
  }
}
```

### C# (.NET)

```csharp
using System;
using System.Net.Http;
using System.Text;
using System.Text.Json;
using System.Threading.Tasks;

public class FirebirdApiClient
{
    private readonly string _apiUrl = "http://85.114.224.45:8000";
    private readonly string _token = "ВАШ_ТОКЕН_ЗДЕСЬ";
    private readonly HttpClient _httpClient;

    public FirebirdApiClient()
    {
        _httpClient = new HttpClient();
        _httpClient.DefaultRequestHeaders.Add("Authorization", $"Bearer {_token}");
    }

    // Пример 1: Простой SELECT запрос
    public async Task<List<Dictionary<string, object>>> ExecuteQuery(string query)
    {
        var requestBody = new
        {
            query = query
        };

        var json = JsonSerializer.Serialize(requestBody);
        var content = new StringContent(json, Encoding.UTF8, "application/json");

        var response = await _httpClient.PostAsync($"{_apiUrl}/api/query", content);
        var responseContent = await response.Content.ReadAsStringAsync();

        if (response.IsSuccessStatusCode)
        {
            var result = JsonSerializer.Deserialize<QueryResponse>(responseContent);
            if (result.Success)
            {
                return result.Data;
            }
            else
            {
                Console.WriteLine($"Ошибка: {result.Error}");
                return null;
            }
        }
        else
        {
            Console.WriteLine($"HTTP ошибка: {response.StatusCode}");
            return null;
        }
    }

    // Пример 2: Параметризованный запрос
    public async Task<Dictionary<string, object>> GetById(string table, int id)
    {
        var requestBody = new
        {
            query = $"SELECT * FROM {table} WHERE ID = ?",
            @params = new[] { id }
        };

        var json = JsonSerializer.Serialize(requestBody);
        var content = new StringContent(json, Encoding.UTF8, "application/json");

        var response = await _httpClient.PostAsync($"{_apiUrl}/api/query", content);
        var responseContent = await response.Content.ReadAsStringAsync();

        if (response.IsSuccessStatusCode)
        {
            var result = JsonSerializer.Deserialize<QueryResponse>(responseContent);
            if (result.Success && result.Data.Count > 0)
            {
                return result.Data[0];
            }
        }
        return null;
    }

    // Пример 3: Получение списка таблиц
    public async Task<List<string>> GetTables()
    {
        var response = await _httpClient.GetAsync($"{_apiUrl}/api/tables");
        var responseContent = await response.Content.ReadAsStringAsync();

        if (response.IsSuccessStatusCode)
        {
            var result = JsonSerializer.Deserialize<TablesResponse>(responseContent);
            return result.Tables;
        }
        return new List<string>();
    }
}

// Классы для десериализации
public class QueryResponse
{
    public bool Success { get; set; }
    public List<Dictionary<string, object>> Data { get; set; }
    public string Error { get; set; }
}

public class TablesResponse
{
    public bool Success { get; set; }
    public List<string> Tables { get; set; }
}
```

### PHP

```php
<?php

class FirebirdApiClient
{
    private $apiUrl = 'http://85.114.224.45:8000';
    private $token = 'ВАШ_ТОКЕН_ЗДЕСЬ';

    // Пример 1: Простой SELECT запрос
    public function executeQuery($query, $params = [])
    {
        $data = [
            'query' => $query
        ];
        
        if (!empty($params)) {
            $data['params'] = $params;
        }

        $ch = curl_init($this->apiUrl . '/api/query');
        curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
        curl_setopt($ch, CURLOPT_POST, true);
        curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
        curl_setopt($ch, CURLOPT_HTTPHEADER, [
            'Authorization: Bearer ' . $this->token,
            'Content-Type: application/json'
        ]);

        $response = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        curl_close($ch);

        if ($httpCode === 200) {
            $result = json_decode($response, true);
            if ($result['success']) {
                return $result['data'];
            } else {
                echo "Ошибка: " . $result['error'] . "\n";
                return null;
            }
        } else {
            echo "HTTP ошибка: $httpCode\n";
            return null;
        }
    }

    // Пример 2: Получение по ID
    public function getById($table, $id)
    {
        $query = "SELECT * FROM $table WHERE ID = ?";
        $result = $this->executeQuery($query, [$id]);
        
        if ($result && count($result) > 0) {
            return $result[0];
        }
        return null;
    }

    // Пример 3: Получение списка таблиц
    public function getTables()
    {
        $ch = curl_init($this->apiUrl . '/api/tables');
        curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
        curl_setopt($ch, CURLOPT_HTTPHEADER, [
            'Authorization: Bearer ' . $this->token
        ]);

        $response = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        curl_close($ch);

        if ($httpCode === 200) {
            $result = json_decode($response, true);
            return $result['tables'] ?? [];
        }
        return [];
    }
}

// Использование
$client = new FirebirdApiClient();

// Получить данные
$data = $client->executeQuery('SELECT FIRST 10 * FROM STORGRP ORDER BY NAME');
if ($data) {
    foreach ($data as $row) {
        print_r($row);
    }
}

// Получить по ID
$item = $client->getById('STORGRP', 123);
if ($item) {
    print_r($item);
}

// Получить список таблиц
$tables = $client->getTables();
echo "Доступно таблиц: " . count($tables) . "\n";
?>
```

## ⚠️ ОБРАБОТКА ОШИБОК

### Коды ответов:

- **200** - Успешный запрос
- **400** - Невалидный SQL запрос (например, UPDATE/DELETE)
- **401** - Неверный или отсутствующий токен
- **404** - Таблица не найдена (для `/api/schema/{table_name}`)
- **500** - Ошибка сервера или базы данных

### Пример обработки ошибок (Python):

```python
import requests

def safe_query(query, token):
    try:
        response = requests.post(
            "http://85.114.224.45:8000/api/query",
            json={"query": query},
            headers={"Authorization": f"Bearer {token}"},
            timeout=30
        )
        
        if response.status_code == 200:
            data = response.json()
            if data["success"]:
                return {"success": True, "data": data["data"]}
            else:
                return {"success": False, "error": data["error"]}
        elif response.status_code == 401:
            return {"success": False, "error": "Неверный токен доступа"}
        elif response.status_code == 400:
            return {"success": False, "error": "Невалидный SQL запрос"}
        else:
            return {"success": False, "error": f"HTTP {response.status_code}"}
            
    except requests.exceptions.Timeout:
        return {"success": False, "error": "Таймаут запроса"}
    except requests.exceptions.ConnectionError:
        return {"success": False, "error": "Не удалось подключиться к API"}
    except Exception as e:
        return {"success": False, "error": str(e)}
```

## 📝 ВАЖНЫЕ ЗАМЕЧАНИЯ

### 1. Безопасность SQL запросов

**✅ Рекомендуется:** Использовать параметризованные запросы
```sql
-- Хорошо
SELECT * FROM TABLE WHERE ID = ?
-- params: [123]
```

**❌ Не рекомендуется:** Конкатенация строк (риск SQL инъекций)
```sql
-- Плохо
SELECT * FROM TABLE WHERE ID = 123  -- если ID из пользовательского ввода
```

### 2. Разрешенные операции

**✅ Разрешено:**
- `SELECT` - выборка данных
- `WITH ... SELECT` - CTE запросы
- `SELECT ... FROM ... WHERE ... ORDER BY ...`
- Подзапросы в SELECT

**❌ Запрещено:**
- `UPDATE` - обновление данных
- `DELETE` - удаление данных
- `INSERT` - вставка данных
- `DROP` - удаление объектов
- `ALTER` - изменение структуры
- `CREATE` - создание объектов

### 3. Производительность

- API использует кеширование (TTL: 10 минут)
- Повторяющиеся запросы выполняются быстрее
- Для больших выборок используйте `FIRST N` или `LIMIT`

**Пример:**
```sql
-- Хорошо - ограничение выборки
SELECT FIRST 100 * FROM LARGE_TABLE

-- Плохо - может быть медленно
SELECT * FROM LARGE_TABLE
```

### 4. Таймауты

- Рекомендуемый таймаут: 30 секунд
- Для сложных запросов может потребоваться больше времени
- При таймауте повторите запрос

### Пример 2: Поиск по нескольким условиям

```python
def search_products(name_filter, min_price=None, max_price=None):
    query = "SELECT * FROM PRODUCTS WHERE NAME LIKE ?"
    params = [f"%{name_filter}%"]
    
    if min_price:
        query += " AND PRICE >= ?"
        params.append(min_price)
    
    if max_price:
        query += " AND PRICE <= ?"
        params.append(max_price)
    
    query += " ORDER BY NAME"
    
    return execute_query(query, params)
```

```python
def get_order_with_items(order_id):

        SELECT 
            o.ID,
            o.DATE,
            o.CUSTOMER_NAME,
            oi.PRODUCT_NAME,
            oi.QUANTITY,
            oi.PRICE
        FROM ORDERS o
        JOIN ORDER_ITEMS oi ON o.ID = oi.ORDER_ID
        WHERE o.ID = ?
        ORDER BY oi.PRODUCT_NAME
    """
```
